# حاسبة مالية متطورة (FinCalc App)

تطبيق Flutter لأندرويد يضم 6 حاسبات مالية مبنية على مبدأ القيمة الزمنية للنقود.
المعادلات والأمثلة المحلولة مصدرها `fincalc_spec.xlsx` (مرفق في المحادثة الأصلية).

## تشغيل المشروع محليًا

هذا المشروع يحتوي على `lib/` و `test/` و `pubspec.yaml` فقط — بدون مجلدي
`android/` و `ios/` (لأنهم يُولَّدان تلقائيًا). قبل أول تشغيل:

```bash
flutter create --org com.yourcompany --project-name fincalc_app .
flutter pub get
flutter test        # لازم تعدي كل الاختبارات الستة قبل أي تشغيل فعلي
flutter run
```

الأمر `flutter create .` هيولّد مجلدات `android/` و `ios/` و باقي ملفات المنصّة
بدون ما يلمس `lib/` أو `test/` الموجودين، لأنهم أصلاً موجودين.

## هيكل المشروع

- `lib/logic/` — دوال الحساب الخالصة (pure Dart)، كل واحدة مطابقة لمعادلات
  الشيت المقابل لها في `fincalc_spec.xlsx`.
- `lib/models/` — `CalculationResult` (كائن نتيجة موحّد) و `CashFlowEntry`.
- `lib/screens/` — شاشة لكل حاسبة + الشاشة الرئيسية وسجل الحسابات.
- `lib/widgets/` — مكونات مشتركة (بطاقة نتيجة، رسم بياني، جدول تدفقات، حقل إدخال).
- `lib/providers/` — إدارة حالة سجل الحسابات عبر `shared_preferences`.
- `test/logic/` — unit tests لكل حاسبة، بنفس أرقام الأمثلة المحلولة في الإكسيل.

## ملاحظة مهمة

كل أرقام unit tests في `test/logic/` تم التحقق منها يدويًا وبمعادلات إكسيل حية
في `fincalc_spec.xlsx` قبل كتابة الكود (راجع خانة "متطابق مع المثال اليدوي؟" في
كل شيت). **شغّل `flutter test` بنفسك قبل أي build على Codemagic** — ده بيئة
توليد الكود الحالية بدون Flutter SDK مثبّت، فالاختبارات لسه محتاجة تشغيل فعلي
على جهازك أو في الـ CI نفسه.

## البناء على Codemagic

حط ملف `codemagic.yaml` (الموجود في نفس المحادثة اللي أنشأت فيها هذا المشروع)
في جذر الريبو بعد ما ترفعه على GitHub، وجهّز التوقيع (keystore) في إعدادات
Codemagic قبل أول build.
